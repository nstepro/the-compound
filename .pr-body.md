## Summary

Makes **the-compound** easier for coding agents and new contributors to work in safely, without changing the `app/` subtree layout or Heroku deploy model.

- **Agent entry points:** root `README.md`, `AGENTS.md`, `.cursor/rules/`, `app/.env.example`, and `app/documentation/ARCHITECTURE.md`
- **Tooling fixes:** corrected `update-data` paths, parser debug fixture, CommonJS `config.example.js`, doc drift (`.env` vs `.env.local`), removed unused `Admin.tsx` wrapper
- **Security:** house mechanics moved from `public/` to `fixtures/` so they are not copied into `dist/` and served statically; production boot fails if JWT/password env vars are still defaults
- **Dev ergonomics:** `npm run dev:all`, `check` / `validate`, `seed-local`, cross-platform `parse-debug`
- **Guardrails:** GitHub Actions CI (lint, typecheck, test, build), Vitest smoke tests, ESLint extended to parser/server JS

## What agents should know

| Topic | Detail |
|-------|--------|
| Working directory | All commands run from `app/` |
| Default dev | `npm run dev:all` (Vite :5173 + API :3000) |
| Local places data | `npm run seed-local` → `public/compound-places.json` (gitignored) |
| House mechanics (local) | `fixtures/house-mechanics/` when GCS disabled |
| Verification | `npm run check`, `npm test`, `npm run validate` |

## Notable file changes
